# Bit Weave · 比特织机

Huffman 无损压缩工坊 —— 把任意文本压成最短比特流，并把背后的**最优前缀码二叉树**画给你看。
单文件 HTML，零依赖、完全离线，打开 `index.html` 即用。

> 核心思想：出现越频繁的符号，分配越短的码字。Huffman 算法保证在「逐符号定长字节」前提下
> 得到**最短期望码长**的前缀码；解码时用同一棵树逐位还原，做到**字节级无损**。

## 特性

- **频率统计**：按 UTF-8 字节统计频次（自动处理中文/emoji 等多字节字符）
- **最优前缀码**：二叉 Huffman 树，叶子=符号、内部节点=合并频率；左支标 `0`、右支标 `1`
- **二叉树可视化**：canvas 绘制整棵树，节点圆内标频率/字符，边标 0/1，可滚动、可下载 PNG
- **编码 / 解码**：实时生成比特流，并验证 `decode(encode(x)) === x`（无损往返）
- **压缩指标**：原始比特、压缩比特、平均码长、压缩比、节省百分比
- **种子无关**：同样输入永远得到同一棵树（确定性 tie-break），不需要随机种子
- **引擎与界面分离**：纯算法引擎挂在 `globalThis.HUFF`，无 DOM 依赖，可单独测试

## 快速开始

直接双击 `index.html`。

1. 在文本框输入（或选「示例文本」/「随机示例」）
2. `生成压缩` → 出频率表 + 码字 + 比特流 + 树
3. `验证无损往返` → 确认解码结果与原文逐字节一致
4. `下载树 PNG` 导出当前树

## 算法与正确性

- 字节 → `freqs` 统计；`buildTree` 用稳定 tie-break（频率相等时按节点 `id`）保证确定性
- `assignCodes` 做前序遍历赋码，保证**前缀码**（任意码字都不是另一码字的前缀）
- `encode` 把码字串按 **MSB 优先**打包进字节；`decode` 按位在树上走，命中叶子即还原一个字节
- **无损不变量**：对任意输入（含空串、单符号、双符号、Unicode）均有 `decompress(compress(x)) === x`
- 单符号特例：只有一个不同字节时，所有出现都编成 `0`（1 位/符号），解码直接回填

## 技术栈

- 纯原生 HTML + CSS + JS（`<canvas>`），无外部库 / 网络请求
- 引擎脚本 `<script id="engine">` 暴露 `globalThis.HUFF`
- 测试：`_smoke.js`（Node + `vm` 沙箱）38 项断言全绿；`_probe.js` 输出 ASCII 频率表/码字/树供肉眼检查

```bash
node _smoke.js   # 引擎断言（频率/前缀码/往返/确定性/边界/压缩合理性）
node _probe.js   # ASCII 探针：频率表 + 码字 + 括号树 + 比特流头
```
